## 프로젝트 소개

**차대유~**는 대전광역시 주차장 정보를 더 쉽게 찾아보려고 만든 웹 앱입니다. 장소나 주차장 이름을 검색해 주변 주차장의 위치와 원천에서 제공하는 상세 정보를 확인할 수 있습니다.

주차 정보는 조회 시점과 데이터 원천의 상태에 따라 달라집니다. 마지막으로 정상 조회한 값과 조회 시각을 보여주며, 새 정보를 가져오지 못하면 기존 값을 지우지 않고 정보가 오래되었을 수 있다고 안내합니다.

## 주요 기능

- 🗺️ 지도와 목록에서 주변 주차장 찾기
- 🔎 장소·주차장 이름 검색, 행정구와 지도 영역별 필터링
- 🅿️ 제공되는 주차 가능 대수, 요금, 운영시간 확인
- 🕒 조회 시각과 데이터 지연 상태 표시
- 📅 주차장별 날짜 기록 저장 및 이전 기록과의 변화 확인
- ↻ 조회 실패 사유 안내와 다시 시도

## 사용 기술

- **화면:** HTML, CSS, JavaScript
- **서버:** Python, FastAPI
- **지도와 장소 검색:** Kakao Maps JavaScript SDK
- **데이터 원천:** [대전광역시 실시간 주차장 정보](https://www.data.go.kr/data/15083717/openapi.do)
- **저장:** SQLite (로컬 개발), PostgreSQL (운영 환경)

## 데이터 안내

주차장 정보는 대전광역시가 제공하는 공개 데이터를 사용합니다. 원천에 등록된 주차장만 표시하므로 대전의 모든 주차장을 포함하지는 않습니다.

- 주차장 위치나 요금 정보가 있어도 실시간 빈자리 정보가 제공된다는 뜻은 아닙니다.
- 빈자리 수가 없거나 확인이 어려운 경우에는 임의로 숫자를 만들어 보여주지 않습니다.
- 원천 응답에 개별 관측 시각이 없어, 앱의 조회 시각과 구분해 안내합니다.
- 조회가 실패하면 마지막 정상값을 보존하고 오래된 정보일 수 있음을 표시합니다.
- 날짜별 변화는 앱에 저장된 기록을 바탕으로 계산합니다.
- 사용자 위치를 추적하거나 개인 위치 정보를 서버에 저장하지 않습니다.

## 프로젝트 구조

```text
.
├─ app.py                 # 웹 서버와 데이터 조회
├─ parking.py             # 원천 응답 검증 및 정규화
├─ storage.py             # 현재 정보와 날짜별 기록 저장
├─ readings.py            # 읽기 값 검증 및 변화 계산
├─ public/
│  ├─ index.html          # 주차 정보 화면
│  └─ assets/             # 화면 스타일과 동작
├─ tests/                 # 자동화된 테스트
├─ .env.example           # 필요한 환경 설정 예시
└─ requirements.txt       # Python 패키지 목록
```
